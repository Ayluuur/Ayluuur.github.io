01 / ACADEMIC PROJECT

MMG: Manipulation-Aware Holistic Motion Generation

An academic project for generating manipulation-aware holistic human motion, using HMD sparse tracking signals collected with SteamVR in Unity.

My primary role in this project was to design interaction scenarios and workflows, acquire HMD data with SteamVR, integrate the neural network model into Unity, and use its inference results to drive an avatar in interaction experiments.

Features
  • SteamVR-based collection pipeline for sparse HMD tracking signals.
  • Interactive Unity scenes for body and hand-object motion experiments.
  • Neural motion inference integrated with real-time avatar control.

02 / ACADEMIC PROJECT

Human–Scene Interaction Motion Generation

An academic project for generating non-penetration human-scene-interaction motion, using HMD sparse tracking signals collected with SteamVR in Unity.

In this project I mainly worked on model network design, all experiments and testing, and model deployment in Unity for interaction experiments.

Features
  • Network design for motion estimation in human-scene interactions.
  • End-to-end experiment setup, testing, and result evaluation.
  • Unity deployment for interactive non-penetration motion demonstrations.
