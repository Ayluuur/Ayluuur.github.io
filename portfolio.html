01 / ACADEMIC PROJECT

Human–Scene Interaction Motion Generation

An academic project for generating real-time non-penetration human-scene interaction motion, using sparse HMD tracking signals collected with SteamVR in Unity.

My Contributions
  • Designed the motion-estimation network for human-scene interactions.
  • Implemented the end-to-end experimental pipeline and conducted model evaluation.
  • Integrated the trained model into Unity for interactive, real-time motion generation.
Features
  • Real-time human motion generation from sparse HMD tracking signals.
  • End-to-end experiment setup, testing, and result evaluation.
  • Unity-based interactive non-penetration motion demonstrations.

02 / ACADEMIC PROJECT

MMG: Manipulation-aware Holistic Human Motion Generation from Sparse Tracking Signals

An academic project for generating real-time manipulation-aware holistic human motion, using sparse HMD tracking signals collected with SteamVR in Unity.

My Contributions
  • Designed the interaction manipulation scenarios and data-collection workflow.
  • Built and evaluated the experimental pipeline.
  • Integrated the neural network into Unity for interactive motion experiments.
Features
  • Coordinated full-body and hand motion generation.
  • Manipulation-aware modeling of hand-object interactions.
  • Neural motion inference integrated with real-time avatar control.
